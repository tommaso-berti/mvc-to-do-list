To-Do List MVC App

A simple web application that allows users to manage a to-do list using the MVC (Model-View-Controller) architecture. Users can add new tasks and remove them once completed.

Project Overview

This project demonstrates how to build a basic web application from scratch using:
	•	Node.js
	•	Express
	•	REST API
	•	MVC architecture

Features
	•	Add a new task to the to-do list
	•	View all tasks
	•	Remove a task by clicking on it
	•	Organized code structure using MVC
